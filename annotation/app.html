Annotation rules
Extract only the patient's medication use or proposed regimens. Exclude procedures, allergy-only mentions, and medications mentioned solely in literature discussion or another person's history. Do not infer missing facts.
Separate strength (5 mg per tablet) from dose (two tablets). Use blank fields for unknown values. Preserve wording. Status is relative to the note's reference time: current, explicitly discontinued, historical, hypothetical, or unknown. Create separate records for different regimens or temporal events.
Evidence spans must support the populated fields and status. Select additional passages when necessary. An explicit denial such as “never took aspirin” is not a medication-use record. Review empty results explicitly. One person's review does not establish independent gold labels.
Text paragraph separators were normalized before annotation. Offsets refer to the exact source text displayed here, using Unicode characters and an exclusive end offset.
